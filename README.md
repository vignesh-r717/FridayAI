# FRIDAY AI 🤖

FRIDAY AI is a Python-based personal desktop AI assistant designed to provide voice interaction and useful desktop automation features.

## 🚀 Features

- 🎙️ Voice-based interaction
- 🔊 Text-to-speech responses
- 🧠 AI-powered response processing
- 🖥️ Desktop graphical interface
- 📂 Application launching
- 💻 System control utilities
- 🔊 Volume control
- 🌦️ Weather functionality
- 💾 Basic memory functionality
- ⌨️ Voice and keyboard interaction

## 🛠️ Technologies Used

- Python
- Speech Recognition
- Text-to-Speech
- AI / LLM integration
- Custom desktop GUI
- Git & GitHub
